# Fore the V — notes for Claude

This repo **is the live tour site**: https://stevepc95.github.io/fore-the-v/ (GitHub Pages, `main` branch, root).
The old Claude artifact link is retired and only shows a "We've moved" banner. Make every site change here.

## How it's built
- `index.html` holds the whole site (HTML, CSS and JS). Pages are `section[data-view]`, routed by `#hash`.
- Navigation (4 Nov): bottom bar (Home, Weekend, Golf, Scores, Bookie, More) + a More sheet (The Feed, The 19th, The Players, Profile, Exec). Merged pages show sub-tabs in `#subnav`: Weekend = schedule/logistics, Golf = courses/formats, The 19th = dops (Log a Fully)/photos/putt, The Players = players ("The 8")/honours, Exec = fines/questions/desk. Router `GROUPS` in the first script; a group hash (`#golf`, `#nineteenth`) opens the last-used sub-tab (`ftv-last-sub`), every old section hash still works. Long content sits in `details.dd` drop-downs (same look as Bookie sections); open state remembered per phone (`ftv-dd`), `data-open-on="YYYY-MM-DD"` opens one on the day. Home has a Next up card (`NEXT` list in the router script). Player cards tap open the bio.
- Supabase backs sign-in, photos, dop videos, fourball pairings, the Wolf wheel and live scoring (`config.js` holds the public URL and anon key). Schema scripts run in order: `supabase/setup.sql`, `002`…`019`.
- Sign-in (script 014): group code, pick your name, then your 4-digit PIN (`ftv_sign_in`). Unclaimed names are claimed first-come by choosing a PIN (an admin name also needs the admin code). PINs are bcrypt-hashed in `player_pins` (no app access); 5 wrong tries locks a name 15 min. Steve resets PINs from his Desk (`ftv_reset_pin`, also signs that name out). The shared Tour V code is retired: rights come from the profile (`is_admin`, `is_captain`, `is_exec`, `is_scorer`; scorer sets `members.tour_access`). Guests ("I'm not on the list") still use `ftv_join`. Sessions are remembered on the phone (anonymous Supabase auth + `members` table).
- Profile tab (`#profile`): claim/PIN, edit first name, surname, photo (private `avatars` bucket, `<player_id>/…`), request changes to tour name/nickname/hometown/bio (`profile_requests` → Steve approves on the Desk), stats. Handicaps are organisers' only. Players tab cards (`data-pid`) are patched live from `players`.
- Profile pics (script 019, 4 Nov, Steve): nobody can change their own pic (`ftv_set_photo` now refuses with `own_photo`); anyone on the list (not the test profile) changes anyone else's from their card on The 8 (`.pl-pic` button, shows when the card is open) via `ftv_set_photo_for`. Storage policy "FTV upload others avatars" allows uploads into other players' folders. Profile page just says the pic is in the boys' hands. Player cards have ids `pl-<id>`. Tapping a pic (player card badge or your own on Profile) opens it big in `#av-lb`, with a Change button when it's someone else's. New pics are stored square at up to 1080px (older ones 480px).
- The Feed (`#feed`, group `feed`, first item in More; script 019): table `feed` (kind `chat`|`app`). Chat goes through `ftv_chat` (members, 500 chars). App messages are written only by DB triggers via `ftv_feed_post` (bets incl. approved pitches, new markets, results, scrapped markets, roulette spins net ≥ +R100k or ≤ −R250k, buy-ins, profile pic changes, approved profile changes, fullies, fully comments, photos, scores locked). Body tokens `{who}` (actor_name, team colour) and `{link}` (link_label → link_href hash, then scrolls to element id link_ref, opening any closed `details` and flashing it). Anchors: `mk-<market id>`, `dv-<video id>`, `pl-<player>`, `rl` (roulette). Test-profile activity is `hidden` (only the poster and Steve see it). Delete own chat; Steve deletes anything. Unread count (vs `ftv-feed-seen` in localStorage) shows on the More button and the Feed item; More button badge = Desk to-dos + unread feed (`window.FTV_BADGE`, `ftvMoreBadge`).
- Steve's Desk (`#desk`, admin only, badge = items waiting): profile change requests, market pitches, markets to settle, who's claimed + PIN resets.
- Usage (script 017, 4 Nov): a small tracker script logs each page open (`documentElement.dataset.page`, plus `open` on app start or after 30+ min away) in batches via `ftv_track` into `app_events` (no direct table access; test profile skipped). Desk's Usage section reads `ftv_usage_stats()` (admin only): active now/today, page opens, Bookie/Casino/fullies/photos totals, most-used pages, busiest hours (SAST), per-person last seen + activity.
- Log a Fully (was Log a Dop; ids/tables still say dop) is for fun (no points): any signed-in member films up to 30 s in-app (camera asks for 4:3 ~1280×960 so front cameras don't sensor-crop; preview and wall use `object-fit:contain` so nothing is cropped; zoom slider + pinch + Widest button appear only where the phone exposes `zoom` capability, starting fully zoomed out); videos in the private `dops` bucket. Each video has a comment section (script 018, `dop_comments`, max 280 chars; name/player stamped by a trigger from the commenter's sign-in; delete own, Steve deletes any; cascades with the video; live via realtime). Comment block per card is collapsed by default (open state + drafts kept in memory across wall reloads). Photos in the private `photos` bucket, tagged via `photos.album`: `t1`–`t5` (Tour I–V) or `random` (old `general` = Random), optional `caption`; uploader or Steve can retag (script 016). The 4 Tour IV archive images in `img/` also show under the IV filter.
- The Bookie (`#bookie`, scripts 009 + 010): fake-money betting. Each of the 8 starts on R1,000,000; past tourists can buy in (`bookie_joins`). **Fixed odds against the house** (010 replaces 009's tote): odds per answer on `markets.odds` (null = answers × 0.9), each bet locks its odds, win = stake × odds. Steve (is_admin) posts markets, sets odds, closes betting, posts answers. Pitched markets (`market_suggestions`) cost R50k; declined = gone, approved = opening bet at double odds (`bets.boost` = 2). The Casino = European roulette table: chips on any number of spots, one spin settles all (`ftv_spin_table`, script 012; rows grouped by `casino_spins.spin_id`); WINNER/LOSER banner when the wheel stops. All money checks happen in the database functions, never in the browser; balance = `ftv_balance()`.
- "Get R250K for free" (Steve, 4 Nov): a joke button under the Bookie wallet (`#free-btn`). Any touch, click, hover or Enter makes it jump to a random spot on screen (fixed position) with a taunt and a tries count (`ftv-free` in localStorage); it goes home after 6 s idle, on scroll or page change. It never pays out and has no database side. Keep it that way.
- Bookie sections (script 015, 4 Nov): markets sit in 5 drop-downs on the Bookie tab, closed by default, open state remembered per phone (`ftv-bk-secs`): weekend (⛳ The Weekend), friday (🐺 Friday: Wolf), saturday (💃 Saturday: Cha Cha Cha), boks (🏉 Springboks vs Italy), other (🍺 Off the Course). Stored in `markets.category`; null/unknown = Off the Course (where approved pitches land). Steve picks the section in the New/Edit market form (`ftv_market_section`). Each section shows open, then waiting, then paid-out markets. Odds were set on 4 Nov at about a 5% house edge.
- Practice Green (`#putt`): canvas one-putt game behind a Start putting lock (so scrolling can't fire a putt); stats in localStorage only (`ftv-putt`). Fixed 60 Hz physics so putts can be simulated. Joke rule (Steve): a dropping putt has a 20% chance (`CURSE_CHANCE`) to lip out round the cup and start a secret 6-putt curse; putts 2-5 are rigged at release (`rig()`: slightly less pace or a fraction of a degree) so they die on the lip or shave the edge; on the 6th a bong swats the ball and sits centre screen smoking, message "Hahahahaha got you". Never show the word "bong" on screen.
- Scores tab (`#live`) is the only scoreboard: Leaderboard tab removed 3 Nov (old `#scores` links redirect to `#live`). Running total board + status chip at the top; Home has a live Inland–Coastal strip that taps through. Steve: no cup card or cup-focused UI.
- Scoring: shots per hole are stored; Stableford points are calculated in the browser from par, stroke index (course cards in the scoring script) and full handicap. Friday = Wolf (calls in `wolf_calls`; Blind 4 / Lone 3 / Partner 1, confirmed 3 Nov), Saturday = Cha Cha Cha (best 1/2/3 staggered). Rounds can be locked by captains/Steve.
- Exec-only tabs (Fines, Planning) are shown to Steve, Nic, Brandon, Guy with a "Hidden tab" flag. Their fine ideas (golf / general / random) and planning items live in `exec_items` (script 007), shared and live; before 007 runs, Fines shows the draft list and Planning falls back to on-phone ticks.
- Test profile (script 011): `steve_test` ("Steve Test", `players.is_test`) is a regular non-admin punter. Only reachable from an admin phone via Account > Switch to test profile (`ftv_switch_test`; `members.test_of` remembers the real player; a trigger blocks picking it at sign-in). Its bets, spins and pitches are hidden from everyone except itself and Steve; `ftv_test_reset` wipes them. Hidden from the sign-in list (ids ending `_test`).
- Codes live in Supabase (`tour_secret`; Steve's personal admin code in `admin_codes`, script 013), never in this repo or the chat. Signing in as an admin always needs a code (`ftv_code_ok`): the personal one once set, else the shared Tour V code; the shared code stops working for him once his own is set.
- Installable via Add to Home Screen (`manifest.webmanifest`, `icons/`).
- Push to `main` and the site updates in about a minute.
- Supabase project id `hlzmprtoofinzvzinvtf`. When the Supabase connector is attached, run non-destructive SQL directly with `execute_sql` (creates, inserts, `create or replace`). `apply_migration` and anything with drop/delete ask for a confirmation that Steve's mobile app auto-cancels, so hand him those as a script file to paste into the SQL Editor. Always keep the matching `supabase/0NN_*.sql` file in the repo up to date.

## Design rules (keep it looking paid-for)
- Use the colour and font tokens in the `:root` block; never hard-code a colour that only works in light or dark mode.
- Inland = jacaranda purple (`--inland`), Coastal = ocean teal (`--coastal`), club green masthead, gold `--flag` for highlights and TBC chips.
- Fonts: Big Shoulders Display (headings), Instrument Sans (body), IBM Plex Mono (labels, times), Permanent Marker (nicknames only), Libre Baskerville (FTB badge and honours board only).
- New sections follow the existing pattern: `.head` (eyebrow + `h2`), then `.card`s; reuse existing components before inventing new ones.
- Must work on a phone at 360px wide with no sideways scroll.
